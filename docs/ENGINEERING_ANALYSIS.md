# Engineering Analysis

The current extraction pipeline is deterministic and rule-based: it reads PDF text and vector geometry, then classifies recognized dimensions, fits, threads, geometric tolerances, surface finish, hardness/treatment callouts, and form features with confidence and engineer-review flags. It does not call an AI/vision model or infer feature semantics from pixels.

It recognizes common metric dimensions, explicit inch and fractional-inch dimensions, metric threads, and fractional Unified National thread designations. Explicit text labels identify dimensions such as head outer diameter/thickness, socket size, thread length, overall length, or shank length. For a socket-head screw drawing without those labels, a tightly scoped layout heuristic can propose head OD, head thickness, and thread length from a three-callout aligned row, and associate a fractional callout with the socket. These geometry-based roles are marked for engineer confirmation. Socket-head screw title blocks can provide part number, product description, and common stainless material specifications even when those fields are not labeled consistently.

Recognition is limited to text available in the PDF or text recovered through configured Tesseract OCR. Bare numeric dimensions without a nearby label remain explicitly unclassified and require review; visual-only features such as knurling are never reported as extracted without a text callout. Image-only drawings require OCR. Symbol-only GD&T, datum-frame segmentation, and complex geometric relationships may not be recognized reliably. A missing callout is not evidence that the feature is absent.

Extracted dimensions, precision fits, form features, and geometric tolerances require engineer review before manufacturing route generation. The project inspection workspace displays the source PDF, overlays positioned callouts where bounding boxes are available, and persists accepted, corrected, or rejected decisions. CTQ checklist and first-article/PPAP structures are non-certifying drafts that require engineer/customer completion. STEP/CAD extraction is not currently supported.

General manufacturing routes require configured cost templates for every supported feature type; missing rates fail route generation with a clear error rather than inventing cost or time. Socket-head screw routes use the user-supplied per-part baseline rates for an 18-8 stainless, 1,000-piece batch. Route steps are included only when applicable features/material are detected; thread rolling requires an extracted thread and knurling requires an explicit textual knurl callout. These fastener rates are planning estimates, not a shop-specific costing model: cycle times are not provided, and material usage, setup, labor, overhead, yield, tooling, and shipping are not independently calculated. Quotes multiply approved per-part operation rates by the RFQ quantity and preserve these assumptions for review.
